# Pacman Game in Python

## Description
This is a simple implementation of the classic Pacman game using Python and the Pygame library. The game features the iconic Pacman character navigating a maze, eating dots, avoiding ghosts, and collecting power-ups.

## Features
- Classic Pacman gameplay
- Multiple levels
- Ghost AI with different behaviors:
  - **Blinky (Red)**: Follows Pacman directly.
  - **Pinky (Pink)**: Tries to cut off Pacman by moving to the tile ahead.
  - **Inky (Blue)**: Sets traps for Pacman by working with Blinky.
  - **Clyde (Orange)**: Has a random behavior pattern.
- Power-ups
- Score tracking

## Requirements
- Python 3.x
- Pygame library
